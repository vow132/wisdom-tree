## 仍需在目标环境核验

本机没有 Docker Engine 和独立 PostgreSQL 服务，未执行容器镜像构建、Caddy HTTPS 流式转发、pg_dump／pg_restore 的实际备份恢复，也未证明原生 PostgreSQL 多连接的竞态行为。迁移、生产 Compose、Caddy、Dockerfile 和备份恢复脚本均随源码交付。PGlite 并发测试由适配层串行化，不能替代生产 PostgreSQL 的行锁验收。

真实 GitHub／Linux Do 应用凭证、域名和服务器尚未配置。三种登录中外部 OAuth 的真实平台授权必须在配置凭证后再验收；模拟服务验证不等于真实平台验证。Claude Code 接入示例已交付，实际客户端测试使用 Codex CLI 和 Anthropic SDK。

严格 PC／GOTY 画面仍有素材来源与颜色／菜单差异，见项目根 `design-qa.md`。

语料完整性是原始资源 80 个数字对白键的完整覆盖；正文采用独立中文玩法事实摘要和原创闲聊，不是官方逐字中文对白，见 `wisdom-corpus.md`。后台截图中的第 81 条是隔离数据库的 CRUD 测试数据，没有写入实际预览数据。

v4 截图中 `wisdom-tree-ui` 与“你好”规则只存在于隔离浏览器 QA 数据库；实际预览中原模型 ID、管理员自定义显示名称和回复库保持不变。升级前本机数据库及加密主密钥备份存于 `D:\智慧树\.local\backups\pre-v4-20261005`，不包含在公开源码压缩包中。

v5 截图中的第三方应用凭证也是隔离测试值，没有配置到实际预览。真实第三方平台仍需用户填入自己的应用凭证后授权验证；测试使用本地 HTTP 模拟平台。v5 升级前的本机数据库及主密钥另保存在 `.local/backups/pre-v5-20261005`，不随源码压缩包分发。

浏览器工具当前不提供原生指针拖放，因此真实浏览器只验按钮施肥和键盘／按钮讲话，指针路径由真实组件和原图 alpha 的测试覆盖。没有把此项宣称为真机触屏实测。2 核 2GB 实机负载尚未压测；低负载设计包括 5 连接池、256MB Node 堆、前端无轮询与隐藏画布暂停。
