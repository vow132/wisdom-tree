# 智慧树对白语料与动作核验

本次已按原始资源的 **80 个数字对白键**建立完整索引，并为每个键准备可导入的中文返回文本。中文内容由玩法事实摘要与原创闲聊组成，**不是原版逐字台词，也不是官方中文本地化**。这是对“先全部导入试效果”的演示语料：80 条均可轮换，高度字段只保留来源审计信息，不限制默认演示。

## 完整性依据

主索引来自 [FregD156/PvZ_Assets 的原始 LawnStrings.txt](https://github.com/FregD156/PvZ_Assets/blob/8ba94e95cfe7d0de5682f8258d3b932dbdac885c/properties/LawnStrings.txt)，固定 commit 为 `8ba94e95cfe7d0de5682f8258d3b932dbdac885c`。该仓库是初代 macOS 资源公开转储；没有将其宣称为官方发布或已逐字核验的 PC／GOTY 中文资源。文件为 Windows-1252，91,143 字节，SHA-256 为 `c6c6f7984d747600621f7bbd077ed27fb192323c48ca5c850788454758a1477e`。

| 原始数字键 | 数量 | 用途 |
| --- | ---: | --- |
| `1…48` | 48 | 初次施肥说明与按顺序出现的玩法提示 |
| `49` | 1 | 50 英尺以后多数施肥时重复的回应 |
| `101…110` | 10 | 通用闲聊 |
| `201…205` | 5 | 幼树闲聊 |
| `301…305` | 5 | 成树闲聊 |
| `401…405` | 5 | 高树闲聊 |
| `500` | 1 | 复述提示的开场 |
| `600` | 1 | 初次施肥前的提示 |
| `800 / 900 / 1000` | 3 | 100／500／1000 英尺里程碑 |
| `1100` | 1 | 超过 1000 英尺后的回应 |
| **合计** | **80** | 无遗漏、无重复数字对白键 |

`TREE_OF_WISDOM_HIEGHT` 是高度标签（原始键本身拼成 HIEGHT），`TREE_FERTILIZER_TOOLTIP` 是工具提示，访问对话框、植物名称与成就文字也不是树说的对白，因此不计入 80 条。经核验，字符串文件里只有这些 80 个 `TREE_OF_WISDOM_<数字>` 键。

同一条高树回应可出现很多次，不应把施肥次数当成不同语录数量。[GameFAQs 的亲历 PC 记录](https://gamefaqs.gamespot.com/windows-mobile/634831-plants-vs-zombies/faqs/62911)和 [TapTap 中文攻略](https://www.taptap.cn/moment/15205218450932734)可以交叉核对连续提示顺序、50 英尺后重复以及三个里程碑。GameFAQs 作者明确说明最初五条不保证逐字准确；TapTap 清单没有闲聊组，部分植物名也有翻译偏差。二者只作旁证，未直接抄入中文语料。

## 高度与原版动作

高度与动作顺序另参考 [社区重建的 Challenge.cpp](https://github.com/Patoke/re-plants-vs-zombies/blob/c4692036c5e11d227c8fb7c593b734dac96da028/Lawn/Challenge.cpp#L5419-L5741)，固定 commit 为 `c4692036c5e11d227c8fb7c593b734dac96da028`。这是逆向重建，不能等同于官方开源代码，因此以下运行时行为属于有明确代码依据的推断。

- 原版 2…50 英尺的施肥提示编号为高度减一；普通高树阶段使用 `49`；100／500／1000 英尺分别选择 `800 / 900 / 1000`；1000 英尺以上选择 `1100`。
- 幼树闲聊组对应 2…11 英尺，成树组对应 12…49 英尺，高树组对应 50 英尺以上。重建代码使用 `Rand(4)`，因此三个组的第五条 `205 / 305 / 405` 虽在字符串文件中存在，却没有被这段闲聊代码选择。本项目仍导入它们，避免漏掉原始资源中的条目。
- [原始 TreeFood.reanim](https://github.com/FregD156/PvZ_Assets/blob/8ba94e95cfe7d0de5682f8258d3b932dbdac885c/reanim/TreeFood.reanim) 含 `bag`、`seed` 两个图层，共 31 帧、20 FPS，完整倒肥动作约 **1.55 秒**。肥料颗粒在 17…22 与 24…29 帧可见。
- 重建运行逻辑先在游戏坐标 `(340, 300)` 开始倒肥并消耗肥料，清除手持工具；检测倒肥动作播放完后才增高并播放成长动画。成长的运行速率为 **8 FPS**，覆盖树动画 XML 中的 12 FPS 默认值。大树加载停在 `grow50`，继续施肥使用 `grow51`。

交互里的“点击树切换一句话”与触摸拖肥料是本网站按用户要求提供的交互扩展；原版依据用于视觉、动画和先倒肥再长高的顺序。原版控制台彩蛋提示只介绍原游戏，不代表本网站实现这些僵尸彩蛋。

## 文件与复验

- `backend/data/wisdom-tree-quotes.json`：80 条 `{ id, text, sourceKey, category, minHeight, ... }` 数据。`textKind` 区分 `gameplay-summary` 与 `original-chat`。
- `backend/data/wisdom-tree-sources.json`：来源 commit、文件哈希、80 个原文键的逐条哈希、分类总数、动作资料与编辑状态。
- `scripts/verify-wisdom-corpus.py`：核验条数、ID 唯一性、数字键全集、中文数据哈希和分类；传入原始 ZIP 时，还验证 ZIP、原始文件及 80 条原文哈希。

```bash
python scripts/verify-wisdom-corpus.py
python scripts/verify-wisdom-corpus.py --archive /path/to/github.zip
```

脚本默认验证数据与索引的相互一致性；带 `--archive` 的核验才证明当前索引与固定原始资源一致。原始全文 ZIP 不随项目重复分发。修改中文内容后需同步更新 `corpus.sha256`；管理员在数据库中编辑模型返回文本不改变此初始语料文件。

## 文本使用边界

原版对白、角色和素材的权利仍属于各自权利人。公开可下载不代表获得完整台词再发布授权。本项目交付的是独立写成的玩法事实摘要与原创闲聊，并保留来源键帮助检查覆盖范围；没有附带完整外部英文原文或拷贝社区攻略全文。严格的原版逐字中文台词复刻，仍需可使用的授权文本或用户自行提供的语料。
