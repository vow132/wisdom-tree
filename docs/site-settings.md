# 网站设置

管理员打开“管理控制台 → 网站设置”（`/admin/site`），可修改网站的展示内容。养成、价格和限流继续在“养成与 API 规则”中管理。

## 基本信息

| 字段 | 显示位置 | 长度 |
| --- | --- | --- |
| 网站名称 | 导航栏文字品牌、花园场景工具栏；上传 Logo 后作为品牌图片的名称 | 1–60 字符 |
| 浏览器标题 | 浏览器标签页 | 1–120 字符 |
| 花园说明 | 花园标题下方 | 0–200 字符，留空隐藏 |
| 页脚文案 | 网站底部 | 0–300 字符，留空隐藏 |

表单提供文字预览。点击“保存基本信息”后保存到数据库，并直接更新当前页面的导航、说明、页脚和浏览器标题；失败时保留输入内容，显示错误后可修改重试。内容按普通文字显示，不执行 HTML。新访问的页面读取一次公开配置，已打开的其他浏览器需重新打开或刷新页面获取变化。

## 网站图片

支持静态 PNG、JPEG、WebP，每张不超过 2 MB。选择文件只产生本地预览；点击“上传图片”才会上传并替换对应图片，取消选择不会改动网站。图片上传、恢复默认与文字保存相互独立。

| 图片 | 显示与处理 | 恢复默认 |
| --- | --- | --- |
| 网站 Logo | 替代导航栏文字品牌，建议透明横版；自动转换 WebP，最大边长 1024 像素 | 显示网站名称 |
| 浏览器图标 | 标签页图标，建议正方形；自动转换 PNG，最大边长 256 像素 | 使用浏览器默认图标 |
| 花园背景 | 替换 Canvas 的背景层，建议 4:3；自动转换 WebP，最大边长 2560 像素；其他比例居中裁切铺满 | 使用原版背景 |

上传源图片边长不得超过 4096 像素、总像素不得超过 800 万。服务端校验实际格式、完整解码并重新编码，去除元数据；不支持 SVG、GIF 或动画图片。页面无需输入外链地址，图片只从本站受控路径加载。浏览器未能载入 Logo 时显示文字品牌，背景载入失败时保持原版场景。

图片保存在 `SITE_UPLOAD_DIR` 指定的持久目录，默认本机预览位于 `.local/site-assets`，Docker 使用独立持久卷。图片不写入 Git、源码压缩包或镜像。文本与图片引用保存在数据库，部署升级保留持久目录。

恢复默认只清除当前图片引用，历史已管理图片仍保留，便于旧数据库备份恢复。历史图片存储上限为 1000 张或 1 GB，达到上限后停止新上传并提示联系服务器管理员；不能通过反复上传无限占用空间。数据库与图片需配套备份，详见 [图片备份恢复](site-assets-backup.md)。

## 网站更新

同一页面下方的“网站更新”配置沿用现有独立 Token 表单与 CI/CD。更新 Token 仅能写入、不会回显；保存基本信息或图片不会覆盖它。导航栏 GitHub 图标继续指向项目仓库，状态点仍只在首次打开和手动操作时检查版本。开启方式见 [网站更新说明](website-updates.md)。

所有配置与图片修改由服务端验证管理员权限和请求 Origin，审计记录管理员及修改前后的配置，不存储图片 Base64。配置读取、保存后缓存更新和图片载入均没有前端轮询。
