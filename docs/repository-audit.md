## 镜像范围与实际限制

后端运行镜像只复制编译输出、迁移和公开语料；前端运行镜像只复制构建后的静态网站与 Nginx 配置。数据库和 Caddy 镜像基于官方运行镜像，不复制服务器环境文件。工作流没有把生产密码、加密主密钥或 SSH 私钥作为 build arg 或构建文件传入。

GHCR 拉取令牌通过 SSH 标准输入传递，只写入临时 `DOCKER_CONFIG`，结束时删除；SSH 私钥保存在 GitHub Secrets 并临时写入 runner 的临时目录，发布后清理。发布包中的 `.release.env` 只记录提交 ID 和四个不可变镜像引用，服务器持久 `.env` 不随包上传。

本次对镜像的结论基于 Dockerfile、构建上下文规则、工作流和实际 build record；没有导出并逐层解包全部 GHCR 运行镜像。扫描针对可达历史、归档原始字节、常见凭据格式和已知实际值，不声称识别任意未知编码、OCR 未识别的细小像素或服务器全部文件。今后新增凭据、截图、工作流或 Docker COPY 路径，应重新审计相应范围。
